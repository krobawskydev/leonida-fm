# Catálogo de estaciones

El catálogo incluye 23 playlists de Spotify y 8 emisoras de YouTube. Las dos plataformas comparten el orden por familias musicales y la frecuencia de cada emisora. Los enlaces de Leonida FM apuntan a `localhost:3002` para probar la versión local. En «Resultado», anota si la emisora reproduce dentro de la radio. Si falla, registra la fecha, el navegador y el aviso que aparece.
